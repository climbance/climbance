# The cold sitting, running

A wireframe of the page `README.md` specifies, drawn at low fidelity.
`../../../README.md` gives how a wireframe is read.

```
+- /cold/s-3e7a, running -----------------------------------------------+
| Climbance    [ Practice ]  Problems  Cards  Knowledge           ☀  ≡   |
+------------------------------------------------------------------------+
| < Board    Cold problem          47:56 left           [ End ]          |
+----------------------------------+-------------------------------------+
| the statement, as prose          | +----------------------------+      |
|                                  | | def solve(piles, h) -> int:|      |
| ...........................      | |     |                      |      |
| ...........................      | |   the editor               |      |
| ...........................      | +----------------------------+      |
|                                  | [ Submit ]  Cmd+Enter . judged      |
|                                  |             against the problem's   |
|                                  |             own test cases          |
|                                  | +----------------------------+      |
|                                  | | Not solved: case 8,        |      |
|                                  | | wrong answer               |      |
|                                  | +----------------------------+      |
+------------------------------------------------------------------------+
```

- The bar holds no title, and the statement column holds no record line and
  no `Report this problem` press. The press opens the retirement dialog, which
  names the problem, and the ended screen offers it.
- The clock has no press, since a cold sitting does not pause.
- Once solved, the verdict reads `Solved`, and a line under the bar says that
  End shows the problem.
