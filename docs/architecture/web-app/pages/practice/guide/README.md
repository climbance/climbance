# The guide

The page at `/start` on the web and the Guide screen on the phone, under no
section. The guide says what each kind of practice trains and where a new
user starts.

[`guide.md`](guide.md) draws the page at low fidelity.

- **The guide says what each kind of practice trains and where to start.**
  It names the sitting, the recall, judging a solution, filling a key line
  and a question, each with what it trains and where it is reached. Under the
  sitting it names the claim, and says that the board counts the claim's
  answer. A new user meets the claim at the first solve, and no other text
  says what the claim is for.
  It then names two starts: the board's pick for the algorithms, and a
  module's first lesson for the knowledge. A user who is not the author
  otherwise meets five kinds of practice with nothing saying how they differ.
- **The board links the guide while the user's log holds no act**, and the
  account menu links it always. `../board/README.md` and
  `../../shell/README.md` give each link.
- **The guide's way back names the board**, since the guide's two starts both
  begin there.
