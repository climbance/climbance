# A technique's candidates

A wireframe of the page `README.md` specifies, drawn at low fidelity.
`../../../README.md` gives how a wireframe is read.

```
+- /techniques/binary-search --------------------------------------------+
| Climbance    [ Practice ]  Problems  Cards  Knowledge           ☀  ≡   |
+------------------------------------------------------------------------+
| < Board                                                                |
| binary-search                                                          |
|                                                                        |
| Cards  2                                                               |
| Binary search                binary-search    5 templates, 1 optional  |
|   A sorted array, or any space with a monotone predicate over it ...   |
|   recall · · · · ·                                                     |
| Answer-space search          answer-search    3 templates              |
|   The answer is a number, and feasibility is monotone in it ...        |
|   recall · · ·                                                         |
|                                                                        |
| Problems  2                                                            |
| Smallest feasible speed  (medium)  2 attempts  1/2 solved  6 days ago  |
| Split the array          (hard)    never attempted                     |
+------------------------------------------------------------------------+
```

- The cards come first, each as its row on the cards list reads, with its
  progress and its recall. A card is offered, and no sitting requires one.
- A row is a problem: its difficulty as a badge, then the counts at the right.
  A problem nobody attempted reads `never attempted`.
- A row carries no statement, since the clock starts when the statement is
  served.
