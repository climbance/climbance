# A lesson

A wireframe of the page `README.md` specifies, drawn at low fidelity.
`../../../README.md` gives how a wireframe is read.

```
+- /knowledge/lessons/python/names --------------------------------------+
| Climbance    Practice  Problems  Cards  [ Knowledge ]           ☀  ≡   |
+------------------------------------------------------------------------+
| < Lessons                                                              |
| Names and binding                                                      |
| Python . teaches Core . Names, Foundation and Associate . ~6 min       |
|                                                                        |
| the lesson's text, in the reading column                               |
|                                                                        |
| Next: Mutability, Closures                                             |
|                                                [ Mark read ]           |
+------------------------------------------------------------------------+
```

- The text reads as authored prose, on the design tokens.
- Mark read is the act, and returns to the page the lesson was opened from.
  Mark unread replaces it once the lesson is read.
- A link inside the text to another lesson opens that lesson on this page.
