`../../../README.md` gives how a wireframe is read.

- The sections read in the order the author acts on them: what waits first,
  then what learners reported, then what failed, then the spend.
- A waiting row names its command, so the author knows what to run.
- A day with no fault reads no row in the faults table, unlike the product
  page's days, since the table counts failures rather than use.
