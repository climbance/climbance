# The author navigation

A wireframe of the navigation `README.md` specifies under `## The
navigation`, drawn at low fidelity on the problems page. `../../README.md`
gives how a wireframe is read.

```
+- /author/problems -----------------------------------------------------+
| Climbance    Practice  Problems  Cards  Knowledge               ☀  ≡   |
+------------------------------------------------------------------------+
| Inbox        5 │ Problems                                              |
|                │                                                       |
| CONTENT        │ served ▾  technique ▾  target ▾  …                    |
| Questions      │                                                       |
| Lessons        │ Sliding Window Temperature …                          |
| Cards          │ Smallest Valid Cyclic Shift                           |
| ▌Problems      │ Circular Circuit Power Run                            |
|                │ …                                                     |
| FIGURES        │                                                       |
| Product        │                                                       |
| Generation     │                                                       |
| Spend          │                                                       |
|                │                                                       |
+------------------------------------------------------------------------+
```

- The navigation reads as a column left of the page, in three groups. The
  inbox stands alone at the top, then the content browser's pages under
  `CONTENT`, then the figures under `FIGURES`. `▌` marks the page in view.
- The inbox's entry counts the rows that wait, here five, at the column's
  right edge.

In a narrow window the column folds into one menu, opened from the button
above the page's title:

```
+- /author/problems, narrow ---------------------------------------------+
| Climbance    Practice  Problems  Cards  Knowledge               ☀  ≡   |
+------------------------------------------------------------------------+
| [ ≡ Author 5 ]                                                         |
| Problems                                                               |
| served ▾  technique ▾  …                                               |
+------------------------------------------------------------------------+
```
