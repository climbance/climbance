# The terms of use

A wireframe of the page `README.md` specifies, drawn at low fidelity.
`../../README.md` gives how a wireframe is read.

```
+- /terms ---------------------------------------------------------------+
|                                      no navigation                     |
|                                                                        |
| < Sign in                                                              |
| Terms of use                                                           |
| Last updated 24 November 2026                                          |
|                                                                        |
| the terms, as prose                                                    |
| ...........................................................            |
| ...........................................................            |
+------------------------------------------------------------------------+
```

- The page carries no navigation and sends no request, so a person with no
  account reads it.
- The terms' own title and the date they were last updated are the page's
  header, and the prose under it starts at the first section.
